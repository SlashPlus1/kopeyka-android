# Копейка для Android

Учёт трат, лимиты по категориям и планируемые покупки. Все данные остаются на телефоне.

## Как получить .apk

Способ 1. Без установки программ, через GitHub
1. Создайте приватный репозиторий на github.com и загрузите в него все файлы этой папки, включая скрытую папку `.github`.
2. Откройте вкладку Actions, выберите Build APK и нажмите Run workflow.
3. Через 3-5 минут откройте завершённый запуск и скачайте `kopeyka-apk`. Внутри будет `app-debug.apk`.

Способ 2. Android Studio
1. File, Open, выберите эту папку, дождитесь синхронизации Gradle.
2. Build, Build Bundle(s) / APK(s), Build APK(s).
3. Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

Способ 3. Командная строка (нужны JDK 17 и Android SDK)
`./gradlew assembleDebug`

## Установка
Скопируйте `app-debug.apk` на телефон, откройте его и разрешите установку из этого источника.

## Включение автоматического учёта
Откройте раздел «Анализ», блок «Автоматический учёт».
- «Разрешить»: доступ к входящим СМС и показ напоминаний.
- «Открыть настройки»: включите Копейку в списке доступа к уведомлениям. На Android 13 и новее приложение, установленное из файла, сначала нужно разрешить: Настройки, Приложения, Копейка, меню с тремя точками, «Разрешить ограниченные настройки».
- Найденные операции появятся на экране «Обзор». Каждую можно добавить, изменить или пропустить.

## Что приложение делает с данными
- В манифесте нет разрешения INTERNET, приложение не может отправить данные в сеть.
- Автоматическое резервное копирование Android выключено.
- Сохраняются только СМС и уведомления, где есть слово об операции и сумма в рублях. Остальное игнорируется.
- Записи лежат в закрытом хранилище приложения. Если удалить приложение или очистить его данные, они пропадут. В «Анализ, Данные» есть копия в буфер обмена и восстановление.

## Голосовой ввод
Кнопка «Говорить» в быстром вводе использует службу распознавания речи телефона с пометкой «предпочитать офлайн». Работает ли распознавание без сети, зависит от установленного на телефоне русского языкового пакета. Если его нет, служба Google может обратиться к сети уже без участия приложения.

## Известные ограничения
- Проект не собирался и не запускался на устройстве при подготовке, возможны мелкие правки при первой сборке.
- Банки пишут по-разному. Разбор сообщения подбирает категорию и магазин по словам, поэтому каждую операцию стоит проверять.
- Если банк присылает и СМС, и пуш, одна операция может появиться дважды. Приложение помечает такие записи.

## Правила чтения СМС (версия 1.2)
Раздел «Анализ», блок «Автоматический учёт».
- «Правила чтения»: можно задать, от каких отправителей и с какими словами брать сообщения и какие слова пропускать. Есть проверка: вставьте текст СМС и увидите, будет ли оно принято и почему нет.
- «Журнал СМС»: последние сообщения, которые увидело приложение, и причина, почему каждое принято или пропущено. Если журнал пуст после прихода СМС, Android не передаёт их приложению.
- «Найти в СМС за 30 дней»: просматривает уже пришедшие СМС по правилам. Нужно отдельное разрешение на чтение СМС. Уже обработанные сообщения повторно не добавляются.
